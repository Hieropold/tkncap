# tkncap
CLI viewer of current tokens capacity for Claude Code and Gemini

## Build

You can build the project using the standard Go toolchain. First, ensure all dependencies are downloaded:

```bash
go mod tidy
```

Then build the project:

```bash
go build -o tkncap .
```

To install it directly to your `$GOPATH/bin`:

```bash
go install .
```

## Configuration

`tkncap` discovers accounts via environment variables at runtime. No configuration file is required.

The environment variable naming convention is:
`TKNCAP_<PROVIDER>_<ACCOUNT>_<FIELD>=<value>`

### Setting up multiple Claude accounts

To check usage and quotas for multiple Claude accounts simultaneously, configure an environment variable for each account, ensuring that the `<ACCOUNT>` label is unique (e.g., `WORK`, `PERSONAL`).

For Claude, the required `<FIELD>` is `CREDENTIALS_PATH`, which should point to the session credentials file generated by Claude Code.

Example configuration for multiple accounts:
```bash
export TKNCAP_CLAUDE_WORK_CREDENTIALS_PATH=/home/user/.claude/.credentials.json
export TKNCAP_CLAUDE_PERSONAL_CREDENTIALS_PATH=/home/user/.claude-personal/.credentials.json
```

Once exported, running `tkncap show` will automatically discover and display the token capacity for both configured accounts.
